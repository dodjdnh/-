## 命名约定

- 学年学期统一使用 <code>YYYY-YYYY(1)</code> 或 <code>YYYY-YYYY(2)</code>。
- 答案文件统一使用 <code>-答案</code> 后缀。
- 高等数学上下册统一写作 <code>高等数学C(上)</code> 与 <code>高等数学C(下)</code>。
- 题库统一使用 <code>概率论-第X章题库</code> 或 <code>概率论-综合题库</code>。

## 使用建议

1. 先按课程进入对应目录。
2. 复习历年题时，优先使用“往年试卷”和“参考答案”对照。
3. 章节薄弱时，进入“题库”或“讲义与作业”做专项练习。
4. 概率论/待确认重复项/中的文件尚未完成去重，请人工核对后再删除或替换。

资料目录的更详细说明见 [目录说明.txt](./目录说明.txt)。
